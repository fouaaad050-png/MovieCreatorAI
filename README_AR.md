# Movie Creator AI — النسخة الأولية

هذا مشروع Android أولي باستخدام Kotlin وJetpack Compose.

## ما الذي يعمل حالياً؟
- واجهة عربية أولية.
- اختيار فيديو من الهاتف باستخدام منتقي ملفات Android.
- عرض مراحل الإنتاج المخطط لها.

## ما الذي لم يُنفذ بعد؟
- استخراج الكلام باستخدام Whisper.
- إعادة صياغة النص.
- إنشاء MP3.
- إنشاء ترجمة متزامنة.
- دمج الصوت والترجمة وتصدير MP4 بدقة 1080p.

## بناء APK باستخدام الهاتف فقط
1. أنشئ حساباً على GitHub من المتصفح.
2. أنشئ مستودعاً جديداً باسم MovieCreatorAI.
3. ارفع محتويات هذا المشروع إلى المستودع مع الحفاظ على أسماء المجلدات.
4. افتح تبويب Actions وفعّل GitHub Actions إذا طُلب منك ذلك.
5. شغّل مهمة Build Movie Creator AI APK باستخدام Run workflow.
6. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل Artifact باسم MovieCreatorAI-debug-apk.
7. فك ضغط الملف لتحصل على app-debug.apk.

ملاحظة: هذا APK تجريبي للتثبيت والاختبار، وليس إصداراً نهائياً للنشر.

## متطلبات البناء
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Android SDK Platform 35

## الخصوصية والحقوق
يجب استخدام الفيديوهات التي تملكها أو لديك إذن باستخدامها. لا يزيل التطبيق حقوق النشر عن المواد المستوردة.
